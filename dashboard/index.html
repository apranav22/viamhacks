How this is measured

  
Every model is run on every saved top-camera picture of a part on cardboard. Each picture is tagged with its role for that model: Training (the model learned from it), Calibration (set its threshold), Held-out (same collection runs, never used for fitting), Unseen run (collected after the model was built). Only Held-out and Unseen numbers measure generalisation; Training and Calibration are sanity checks.

  
Benchmark is a frozen set of 62 pictures (34 good, 28 defective) used to compare models on identical images. A model's benchmark score only counts the pictures it never trained or calibrated on.

  
Defect = positive. Labels are the recorded collection labels, not an independent review; the same physical part appears in many pictures. Defective parts are never used for training. "Uncertain" means no usable verdict (part type not recognised); the live sorter rejects these, and they never count as correct.

  
Routing: size routing picks the part type from the measured size; type classifier uses a ResNet-18 classifier. Models marked "benchmark only" have results on the benchmark pictures only. Top camera only; tape rule excluded.
